

# AMA Session Q&A

**Question1:** What is the difference between `reverse` and `reversed` functions in Python?


**Answer1:** `reverse` changes the list in place. `reversed` returns a new iterator.

**Question2:** What is indexing in Python?

**Answer2:** Indexing is accessing elements of a sequence using their position.


**Question3:** What are different types of indexing?

**Answer3:** Types include positive, negative, slicing, and multi-dimensional indexing.


**Question4:** Difference between `id` and `class` selector in CSS?

**Answer4:** `id` selects one unique element. `class` can select many elements.

**Question5:** What is inheritance?

**Answer5:** Inheritance allows a class to use properties and methods of another class.

**Question6:** What are constraints in SQL?

**Answer6:** Constraints restrict data in a table, e.g., `PRIMARY KEY`, `FOREIGN KEY`, `UNIQUE`.

**Question7:** What happens when we convert a set into a list?

**Answer7:** Elements become ordered and can be indexed, but duplicates are removed in the set.

**Question8:** What is a subquery?

**Answer8:** A subquery is a query inside another SQL query.

**Question9:** What is exception handling in Python?

**Answer9:** It is managing errors using `try`, `except`, `finally`.

**Question10:** What is recursion?

**Answer10:** Recursion is a function calling itself until a base condition is met.

**Question11:** What is boilerplate in HTML and how to create it?

**Answer11:** Boilerplate is basic HTML structure. Use `<!DOCTYPE html>` with `<html>`, `<head>`, `<body>`.

**Question12:** What is a decorator in Python?

**Answer12:** A decorator is a function that modifies another function.

**Question13:** What is a lambda function?

**Answer13:** Lambda is an anonymous function written in one line.

**Question14:** How does constructor overloading help?

**Answer14:** It allows creating objects in different ways with different parameters.

**Question15:** What is inline CSS?

**Answer15:** Inline CSS is style written directly inside an HTML element using `style` attribute.

**Question16:** What is method overloading?

**Answer16:** Method overloading allows multiple methods with the same name but different parameters.
