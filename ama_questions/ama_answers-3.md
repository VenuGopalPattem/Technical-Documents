# Web Development AMA

## How to delete each element of HTML using DOM?

You can remove elements using `element.remove()` or `parent.removeChild(child)`.  
For multiple elements, select them using `querySelectorAll()` and loop through each to remove them.

---

## Can we use POST method for update?

Yes, but it is not recommended in RESTful APIs.  
POST is mainly used to create data, while PUT or PATCH should be used for updating.

---

## What is an Event Listener and its types?

An event listener listens for user actions like clicks or keyboard input.  
Common types include click, keydown, submit, change, and mouseover.

---

## What is a REST API?

A REST API allows communication between systems using HTTP methods.  
It is stateless and usually exchanges data in JSON format.

---

## Web Application vs Web Server

A web application handles logic and user interaction.  
A web server is responsible for serving content and handling HTTP requests.

---

## What is Postman?

Postman is a tool used to test APIs by sending HTTP requests.  
It helps developers view responses and debug backend services.

---

## What are protocols? Explain some protocols

Protocols are rules that define how data is transmitted over a network.  
Examples include HTTP, HTTPS, and FTP.

---

## What is an API?

An API allows different software systems to communicate with each other.  
It acts as a bridge between the frontend and backend.

---

## Types of Web Applications

Common types include static, dynamic, single-page (SPA), and multi-page (MPA) applications.  
They differ based on how content is loaded and updated.
