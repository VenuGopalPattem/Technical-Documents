### 1. What is a pseudo-class?
A pseudo-class defines a special state of an element in CSS, such as `:hover`, `:active`, or `:focus`.

### 2. What are vw and vh?
`vw` means viewport width and `vh` means viewport height; they size elements relative to the browser window.

### 3. What is Flexbox?
Flexbox is a CSS layout system used to arrange items in a row or column with flexible alignment and spacing.

### 4. What is the difference between border-box and content-box?
`content-box` calculates width/height excluding padding and border, while `border-box` includes padding and border inside the element's width and height.

### 5. What is the difference between class and id?
A class can be used for multiple elements, while an id is unique and used for only one element.

### 6. What are semantic tags in HTML?
Semantic tags describe the meaning of content, such as `<header>`, `<section>`, `<article>`, and `<footer>`.

### 7. Name three CSS Grid properties.
`grid-template-columns`, `grid-template-rows`, and `gap` are common properties used to define grid layouts.

### 8. What is the difference between div and span?
`div` is a block-level element, while `span` is an inline element used for small parts of text.

### 9. What is the difference between Flexbox and Grid?
Flexbox is mainly used for one-dimensional layouts (row or column), while Grid is used for two-dimensional layouts (rows and columns).

### 10. What is a media query?
A media query is used in CSS to apply styles based on screen size or device characteristics.

### 11. Why do we use hover in CSS?
`:hover` is used to apply styles when a user moves the mouse over an element.

### 12. What is z-index?
`z-index` controls the vertical stacking order of positioned elements.

### 13. Explain the CSS box model.
The box model consists of content, padding, border, and margin that together define the layout of an element.

### 14. How do you select adjacent siblings in CSS?
The `+` selector is used to select an element that immediately follows another element.

### 15. What are the different types of position in CSS?
The main types are `static`, `relative`, `absolute`, `fixed`, and `sticky`.
