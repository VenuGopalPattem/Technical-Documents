

# Searching in MDN (Mozilla Developer Network)

## Overview

MDN Web Docs is a primary reference for JavaScript, HTML, and CSS. Efficient searching helps in quickly finding syntax, usage, and examples.

---

## Basic Search

Use the MDN search bar or a search engine.

Example:

```text
array map mdn
```

```text
javascript promises mdn
```

---

## Direct Search Using Browser

Search with keywords followed by `mdn`.

```text
forEach mdn
```

```text
fetch api mdn
```

## Reading MDN Pages

Each MDN page typically includes:

* Syntax
* Parameters
* Return value
* Description
* Examples
* Browser compatibility

---

## Using MDN Examples

Copy and test examples directly.

```javascript
const arr = [1, 2, 3];

const result = arr.map(x => x * 2);

console.log(result); // [2, 4, 6]
```

---

## Quick Navigation Tips

* Use **Ctrl + F** to find keywords on the page
* Check **Examples section first**
* Refer to **Syntax** for correct usage
